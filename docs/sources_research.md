# Исследование 7 потенциальных источников заказов по демонтажу (Москва и МО)

В рамках технического этапа проведено исследование открытых источников по критериям: доступность без авторизации, наличие закупок по сносу/демонтажу, привязка к Москве и МО, стабильность получения данных без обхода защит.

## Детальный анализ выбранного источника №1: ЕАСУЗ Московской области

- **URL витрины**: `https://easuz.mosreg.ru`
- **Проверенные категории по демонтажу**:
  - Категория `13987` (*«Работы по демонтажу и сносу зданий и сооружений»*): **406 активных закупок**.
  - Категория `22894` (*«Работы по демонтажу прочих конструкций»*): **204 активные закупки**.
- **Доступные поля в карточке**: Название, начальная цена (НМЦК), заказчик, ИНН заказчика, адрес объекта, реестровый номер ЕИС/ЕАСУЗ, даты публикации и окончания подачи заявок, статус, спецификация лотов.
- **Технический вердикт**: Полностью покрывает потребности пилота. Реализован и валидирован адаптер `EasuzAdapter`.
