# Opportunity Pilot: AI Tender Service (Demolition & Construction)

**Opportunity Pilot** — автоматизированный сервис мониторинга, парсинга, AI-классификации и подбора строительных закупок и демонтажных подрядов по Москве и Московской области.

Сервис решает задачу первичной фильтрации госзакупок и коммерческих торгов: находит целевые процедуры, отсекает нерелевантные лоты, извлекает параметры (виды работ, адрес, объект, спецтребования) с помощью LLM со структурированным выводом (JSON) и передает карточки в Telegram-бот и базу данных.

---

## 📊 Результаты пилотного этапа

В рамках технического этапа выполнен сбор и полный цикл обработки **100 реальных закупок** по демонтажу и сносу:

| Метрика | Значение | Пояснение |
|---|:---:|---|
| **Всего найдено (found)** | **100** | Закупки, полученные из витрины ЕАСУЗ МО по категории демонтажа |
| **Уникальных (unique)** | **96** | Исключены повторные лоты и зеркальные записи по SHA-256 fingerprint |
| **Релевантных AI (relevant)** | **100** | Классифицированы AI как снос / демонтаж / вывоз строймусора |
| **Подходящих под профиль (matched)** | **99** | Соответствуют фильтрам региона (Мск/МО) и профилю работ |

Сводка зафиксирована в файле `report_metrics.json` и сохранена в базу данных.

## 🚀 Пошаговое руководство по запуску

### 1. Установка зависимостей

Требуется **Python 3.11+**.

```bash
# Клонирование / переход в директорию проекта
cd easuz_pilot

# Создание и активация виртуального окружения (рекомендуется)
python -m venv venv

# Windows PowerShell:
.\venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

# Установка пакетов
pip install -r requirements.txt
```

### 2. Запуск автоматических тестов

Проект содержит полный набор оффлайн-тестов на `pytest`:

```bash
python -m pytest -v
```

Все 8 тестов проходят без внешних сетевых вызовов (используются встроенные фикстуры).

### 3. Сбор и AI-классификация 100 закупок

Запуск полного цикла (сбор с ЕАСУЗ, SHA-256 дедупликация, AI-классификация через Polza.ai, мэтчинг, сохранение в БД и генерация `report_metrics.json`):

```bash
# Сбор 100 закупок из категории 13987 ("Работы по демонтажу и сносу")
python -m app.report --category 13987 --limit 100
```

**Дополнительные параметры CLI:**
- `--category <ID>` — ID категории ЕАСУЗ (по умолчанию `13987`, категория прочих демонтажей — `22894`).
- `--limit <N>` — лимит загружаемых закупок (по умолчанию `100`).
- `--pages <N>` — количество страниц пагинации (автоматически рассчитывается исходя из лимита).
- `--db-url <URL>` — переопределение строки подключения к БД.

### 5. Запуск Telegram-бота

Демо-бот на `aiogram 3` визуализирует отобранные карточки с AI-анализом:

```bash
python -m app.bot
```

**Функционал и команды бота:**
- `/start` — приветствие и интерактивное меню быстрого доступа.
- `/tenders` (или кнопка `📋 Все закупки`) — просмотр полного каталога заказов.
- `/favorites` (или кнопка `⭐ Подходящие`) — просмотр только отобранных пользователем заказов (👍).
- `/stats` (или кнопка `📊 Статистика`) — сводная воронка отбора и суммарный бюджет пула подходящих подрядов в рублях.
- `/profile` (или кнопка `⚙️ Профиль поиска`) — текущие критерии поиска и параметры AI-модели.
- **Интерактивные элементы в карточке:**
  - `🔗 Открыть карточку на ЕАСУЗ` — прямая ссылка на официальную страницу лота.
  - `👍 Подходит` / `👎 Не подходит` — фиксация выбора в БД с мгновенным авто-переходом к следующей закупке.
  - `⬅️ Назад` | `N / 100` | `Вперед ➡️` — двухсторонняя удобная пагинация.

## 🔍 Описание ключевых модулей

### 1. Парсер ЕАСУЗ (`app/adapters/easuz.py`)
- **Метод извлечения**: Двухуровневый. Сначала считывает Angular SSR state (`<script type="application/json">`), извлекая точные серверные данные (НМЦК, даты, статус, ИНН заказчика). При отсутствии скрипта переключается на отказоустойчивый DOM-парсер BeautifulSoup.
- **Стабильность**: Семафоры параллелизма, задержка между запросами, корректные User-Agent заголовки, обработка HTTP 429 и блокировок.

### 2. AI Классификатор (`app/ai/classifier.py`)
- **Гибридная схема**: 
  1. Быстрый rule-based префильтр по ключевым словам и стоп-словам (0ms, 0 токенов).
  2. Глубокий анализ через LLM (`GPT-5.6 Luna` / `openai/gpt-5.6-luna` через шлюз Polza.ai) с принудительным `response_format={"type": "json_object"}`.
- **Извлекаемые поля**:
  - `is_relevant`: флаг релевантности демонтажу/сносу;
  - `category`: `demolition`, `earthworks`, `waste_removal`, `other`;
  - `work_types`: перечень конкретных работ (снос МКД, снос водонапорной башни, разборка фундаментов и т.д.);
  - `object_type`: `residential`, `commercial`, `industrial`, `structure`, `infrastructure`;
  - `requirements`: СРО, спецтехника, лицензии;
  - `confidence`: уверенность модели (0..1);
  - `reason`: краткое текстовое обоснование решения на русском языке.

### 3. Дедупликация (`app/models.py`)
- Формирует SHA-256 хэш на основе нормализованного названия, заказчика и бюджета: `generate_fingerprint()`. Позволяет объединять одинаковые закупки при парсинге нескольких источников.

### 4. Мэтчинг (`app/matching.py`)
- Скоринг закупки под профиль подрядчика (`MatchProfile`): проверка региона, диапазона бюджета, типов объектов и расчет итогового `MatchScore`.

## 📈 Перспективы расширения (Roadmap)

1. **Подключение 2-го источника**: Добавление адаптера **Портала поставщиков Москвы** (`zakupki.mos.ru`) для охвата малых закупок и котировочных сессий столицы.
2. **Фоновый планировщик**: Интеграция `APScheduler` / `Celery` для автоматического сбора каждые 30 минут с мгновенным push-уведомлением в Telegram о новых заказах.
3. **Персональные фильтры**: Привязка Telegram `user_id` к индивидуальным профилям подрядчиков (по районам, видам техники и минимальному чеку).
